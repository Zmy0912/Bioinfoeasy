# Gene to 0 — BED/GFF3 Coordinate Converter

Converts coordinates between BED (0-based, half-open) and GFF3 (1-based,
inclusive) conventions.

## Usage

```bash
cd EN
python bed_converter.py
```

See `EN/QUICK_START.md` / `CN/快速开始.md` to get started, and the `examples/`
folder for sample `.bed` and `.gff3` files.
