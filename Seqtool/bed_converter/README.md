# BED Converter

Coordinate and format converters for BED/GFF3 files.

## Contents

| Tool | Description |
|------|-------------|
| [`gene_to_0/`](gene_to_0/) | BED/GFF3 coordinate converter, converting between 1-based and 0-based coordinates (CN/EN) |
| [`gff3_to_bed_converter/`](gff3_to_bed_converter/) | GFF3 to BED converter with a graphical interface (CN/EN) |

## Usage

```bash
# GFF3 to BED (GUI, English)
cd gff3_to_bed_converter/EN
python gff3_to_bed_gui.py
```

Each tool provides its own `README.md`, quick-start guide and examples.
