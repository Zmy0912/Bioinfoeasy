# GFF3 to BED Converter

A GUI tool that converts GFF3 annotation files into BED format.

## Contents

| Directory | Description | Files |
|-----------|-------------|-------|
| [`EN/`](EN/) | English version | `gff3_to_bed_gui.py`, `README.md`, `QUICK_START.md`, `requirements.txt`, `start_converter.bat` |
| [`CN/`](CN/) | Chinese version | `gff3_to_bed_gui.py`, `README.md`, `快速开始.md`, `requirements.txt`, `start_converter.bat` |

## Requirements

The converter relies mainly on the Python standard library; see
`requirements.txt` for optional extras.

## Usage

```bash
cd EN
python gff3_to_bed_gui.py
```

or double-click `start_converter.bat` on Windows.
