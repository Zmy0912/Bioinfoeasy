# FASTA 标识头批量重命名工具 (fasta_header_renamer)

一个基于 Python + Tkinter 的图形化程序,用于批量管理 **FASTA / FA / FAS** 等基因组序列文件的标识头 (`>` 行)与文件名。无需任何第三方依赖,标准库即可运行。

---

## ✨ 主要功能

### 一、批量标识头管理
- 选择一个文件夹,**自动递归扫描**所有 `*.fasta / *.fa / *.fas / *.fna / *.ffn / *.faa / *.frn` 文件
- Treeview 中显示每个文件的: **文件名 / 序列条数 / 当前首条头 / 新标识头(可填)**
- 支持"原地编辑"模式 —— 双击"新标识头"列即可输入
- 多序列文件自动识别条数,双击行/右键可进入**多序列编辑器**单独改名

### 二、双向改名 (本次核心)
| 方向 | 操作 |
|------|------|
| **标识头 → 文件名** | 把 `>OQ851342.1 Asparagus officinalis ...` 这种头变成文件名 `OQ851342.1.fasta` |
| **文件名 → 标识头** | 把 `NC01.fasta` 这种文件名变成首条标识头 `>NC01` |

### 三、灵活的"选中生效"机制
- 左侧 Treeview 中**点选 / Ctrl 多选 / Shift 区间选**若干文件
- 几乎所有按钮在 **有选中时只作用于选中行**,**无选中时作用于全部**

### 四、多序列编辑器 (Toplevel 弹窗)
- 一行一条序列,可滚动浏览
- 每条可独立修改"新标识头"
- "保存修改到文件" / "从当前头填充" / "清空" 快捷按钮
- 顶部"改名文件"按钮:把文件改名为指定首条头

### 五、其它辅助能力
- 💾 一键:先应用新标识头 + 重命名文件
- 📦 导出全部到新文件夹:把所有改后的 FASTA 复制到指定目录,文件名 = 首条标识头
- 📥 批量填充:从首条头 / 从文件名填充"新标识头"列,便于预览编辑

---

## 🛡️ 安全特性

- **写盘原子化**:先写临时文件再 `os.replace`,中途崩溃不会损坏原始文件
- **线程安全**:扫描/解析在后台线程,UI 不卡顿
- **冲突检测**:目标文件已存在时自动追加 `_1 / _2 …` 避免覆盖
- **预览确认**:写盘前显示"旧头 → 新头"预览,用户取消即终止
- **非法字符清洗**:Windows 禁用字符 `\ / : * ? " < > |` 自动替换为 `_`
- **自动重新扫描**:文件名变化后立即同步 Treeview 与磁盘状态

## 📖 详细使用说明

### 1️⃣ 基本流程 (权威方式)
```
打开程序 → 选文件夹 → 自动扫描 → 在"新标识头"列填写新头 → 点"应用新标识头"
                                                              ↓
                                                       (可选)重命名文件
```

### 2️⃣ 选中 → 改名为标识头 (头 → 文件)
1. 在左侧 **点选 / Ctrl 多选** 若干文件
2. 点击右侧 **`✅ 选中行: 改名为标识头`**
4. 在弹出确认框预览 (展示 8 条样本: `原文件名 → 新文件名`)
5. 点"是" → 文件被改名,Treeview 自动重新扫描

> 取消勾选"**仅用 accession 首段作文件名**"复选框,即可用完整标识头作文件名 (如 `OQ851342.1 Asparagus officinalis chloroplast, complete genome.fasta`)。

### 3️⃣ 选中 → 改标识头 = 文件名 (反向)
1. 同样选中若干文件
2. 点击右侧 **`✅ 选中行: 改标识头=文件名`**
3. 默认仅改每文件的首条序列头 (`NC01.fasta` → `>NC01`)
4. 勾选"**多序列文件中所有序列都改**"则:
   - 第一条 = 文件名 (如 `>multi`)
   - 后续 = `文件名_2`, `文件名_3` …
5. 勾选"**标识头保留扩展名**"则头里带 `.fasta` (如 `>NC01.fasta`)

> 更稳妥的方式:点 **`📥 选中行: 用文件名填充新标识头`**,把结果填到"新标识头"列供预览/手动微调,然后再点 **`📝 应用新标识头`**。

### 4️⃣ 多序列文件单独编辑
- **入口 1**:双击 Treeview 中某行
- **入口 2**:右键 Treeview 中某行
- **入口 3**:选中某行 → 点 **`🧬 编辑多序列…`**

在弹窗里:
- 顶部"新的首条标识头"输入框 → 点 **`改名文件`** 同步文件名
- 中部每条序列独立填写新头 → 点 **`保存修改到文件`** 写盘
- **`从当前标识头填充`** / **`清空`** 快捷批量操作

### 5️⃣ 命名模式复选框说明

| 复选框 | 默认 | 何时切换 |
|--------|------|---------|
| 仅用 accession 首段作文件名 | ☑ | 取消勾选后用完整头作文件名 |
| 多序列文件中所有序列都改 | ☐ | 勾选后,反向改名时所有序列都改 |
| 标识头保留扩展名 | ☐ | 勾选后,反向改名时头里带 `.fasta` |

## 🏗️ 架构概览

### 文件结构
```
D:\零零碎碎\代码\NEW\0918\
├── fasta_header_renamer.py   ← 主程序 (~50 KB, 1192 行)
└── NC01_NC10\                ← 示例数据 (12 个 .fasta, 64 条序列)

    ├── NC02.fasta   (1 条)
    ├── ...
    └── NC10.fasta   (1 条)
```

### 核心模块
| 模块 | 职责 |
|------|------|
| `parse_fasta(path)` | 流式解析 FASTA,返回 `OrderedDict[key -> {header, seq_lines, seq_text}]` |
| `write_fasta_atomic(...)` | 临时文件 → `os.replace` 原子写盘 |
| `sanitize_for_filename(name)` | 清洗 Windows 非法字符 |
| `pick_filename_stem(header, accession_only)` | 头 → 文件名主体 |
| `unique_target_path(target_full)` | 重名自动追加 `_1 / _2 …` |
| `header_from_filename(path, keep_extension)` | 文件名 → 头主体 |
| `class FastaRenamerApp` | 主窗口:扫描、Treeview、按钮分发 |
| `class MultiSeqEditor` | Toplevel:多序列逐条编辑 |

### 线程模型
```
主线程 (UI):   渲染 Treeview / 处理按钮事件
后台线程:       文件扫描 + parse_fasta 解析
通信:           通过 root.after(0, callback) 把结果回传主线程
fallback:       mainloop 未启动时直接调用 callback (用于测试)
```

## ⚠️ 注意事项

- 多序列文件改头后,序列会按 **70 字符/行** 自动换行 (FASTA 习惯),**序列内容本身不会改变**
- "改标识头=文件名"操作是**不可逆**的,务必通过"📥 填充新标识头"列预览后再"应用"
- 若新文件名已存在,自动追加 `_1 / _2 …` 不会覆盖原文件
- 重命名文件后程序会**自动重新扫描**文件夹,无需手动操作
