# 时间标尺生成器

一个功能强大的图形化时间标尺生成工具，特别适用于地质学研究中创建地质年代标尺。

## 🚀 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行程序

```bash
python time_scale_generator.py
```

### 系统要求

- **Python**: 3.6 或更高版本
- **操作系统**: Windows / macOS / Linux

## ✨ 主要功能

### 1. 时间范围设置
- 支持自定义最小和最大时间
- 多种时间单位支持：
  - Ma (百万年)
  - ka (千年)
  - yr (年)
  - Ga (十亿年)
  - 自定义时间单位

### 2. 标尺配置
- **独立的标尺方向控制**
  - 主轴方向：上、下、左、右
  - 刻度线方向：向外、向内、上、下、左、右
- 可调节刻度间隔
- 可调节刻度长度（主刻度和次刻度）
- **时间轴反转**：支持从反方向起零

### 3. 显示选项
- 显示/隐藏时间标注数字
- 显示/隐藏地质年代标尺
- 显示/隐藏地质年代终点时间
- 显示/隐藏标尺终点时间
- 显示/隐藏时间单位标注
- **省略小数点后为0的部分**：智能优化数值显示
- 地质年代类型选择：
  - 代 (Era)：新生代、中生代、古生代、前寒武纪
  - 纪 (Period)：详细的地质纪划分

### 4. 颜色自定义
- 线条颜色
- 刻度颜色
- 标签颜色
- 背景颜色

### 5. 尺寸调整
- 标尺长度
- 标尺厚度

### 6. 快捷预设
- 新生代 (0-66 Ma)
- 中生代 (66-252 Ma)
- 古生代 (252-541 Ma)
- 显生宙 (0-541 Ma)

### 7. 元素编辑
- 点击选择地质年代块
- 编辑元素的可见性、颜色、字体大小等
- 每个元素可独立控制

### 8. 导出功能
- **PDF格式**：高质量矢量格式
- **SVG格式**：可无限缩放的矢量格式
- **PNG格式**：便于分享的位图格式

### 9. 实时预览
- 所有参数修改实时反映在预览区域
- 自动更新，无需手动刷新
- 提供"刷新预览"按钮手动触发更新

### 10. 时间显示精度
- **4位小数精度**：满足精确时间标注需求
- **智能格式化**：可选省略小数点后为0的部分
- **完整单位名称**：显示完整的中文名称和英文缩写

## 📖 使用方法

### 基本操作流程

1. **设置时间范围**
   - 在"时间范围"区域输入最小时间和最大时间
   - 选择合适的时间单位

2. **配置标尺**
   - 在"刻度设置"中调整刻度间隔
   - 使用滑块调整刻度长度
   - 在"标尺方向"中选择主轴方向和刻度线方向
   - 可选勾选"反转时间轴（0从反方向起）"

3. **显示选项**
   - 勾选"显示时间标注"显示/隐藏时间数字
   - 勾选"显示地质年代标尺"显示/隐藏地质年代
   - 勾选"显示年代终点时间"显示地质年代终点标注
   - 勾选"显示标尺终点时间"显示标尺起止时间
   - 勾选"显示时间单位标注"显示完整单位名称
   - 勾选"省略小数点后为0的部分"优化数值显示
   - 选择地质年代类型（代或纪）

4. **自定义外观**
   - 点击颜色按钮修改各元素颜色
   - 调整标尺长度和厚度

5. **使用预设**
   - 点击预设按钮快速加载常用地质时间范围

6. **编辑元素**
   - 在预览区域点击选择地质年代块
   - 点击"编辑选中的元素"按钮
   - 在弹出的对话框中修改元素属性

7. **导出结果**
   - 点击导出按钮选择输出格式（PDF/SVG/PNG）
   - 选择保存位置和文件名
   - 确认导出

## 技术特点

### 时间单位转换
程序内部使用百万年(Mya)作为基准单位，支持多种时间单位之间的自动转换：
- Ma (百万年) ← 1 Ma = 1 Mya
- ka (千年) ← 1 ka = 0.001 Mya
- yr (年) ← 1 yr = 0.000001 Mya
- Ga (十亿年) ← 1 Ga = 1000 Mya

### 时间显示精度
- 默认显示4位小数精度
- 支持智能省略小数点后为0的部分
- 时间单位标注显示完整的中文名称和英文缩写
- 所有导出格式（PDF/SVG/PNG）保持一致的显示精度

### 独立的方向控制
- 标尺主轴方向与刻度线方向完全独立
- 支持主轴位置选择：上、下、左、右
- 支持刻度线方向选择：向外、向内、上、下、左、右
- 支持时间轴反转：0可以从任意方向起

### 地质年代数据
程序内置了完整的地质年代数据：
- 四大地质代：新生代、中生代、古生代、前寒武纪
- 详细地质纪：从第四纪到冥古宙的完整划分
- 每个年代都有对应的颜色标识

### 元素系统
每个渲染元素都是独立的对象，支持：
- 独立的可见性控制
- 自定义颜色
- 字体大小调整
- 位置和尺寸编辑

## 🛠️ 常见问题

### 程序无法启动

**问题1：提示"无法导入PyQt5"**
- 解决：安装PyQt5
```bash
pip install PyQt5
```

**问题2：提示"无法导入reportlab"**
- 解决：安装reportlab
```bash
pip install reportlab
```

**问题3：提示"无法导入svgwrite"**
- 解决：安装svgwrite
```bash
pip install svgwrite
```

**问题4：提示"无法导入Pillow"**
- 解决：安装Pillow
```bash
pip install Pillow
```

### 导出功能问题

**问题：导出PDF或SVG失败**
- 解决：确保已安装所有依赖包
- 确保有写入权限
- 检查磁盘空间

### 显示问题

**问题：预览区域显示异常**
- 解决：
  1. 检查时间范围设置是否合理
  2. 调整标尺长度和厚度
  3. 重启程序

### 数值显示问题

**问题：时间值显示过多小数**
- 解决：勾选"省略小数点后为0的部分"选项

**问题：时间值需要显示完整精度**
- 解决：取消勾选"省略小数点后为0的部分"选项

## 💡 使用技巧

1. **合理设置刻度间隔**
   - 大时间范围使用大间隔（如100 Ma）
   - 小时间范围使用小间隔（如1 Ma）

2. **有效利用预设**
   - 预设按钮可快速加载常用地质时间范围
   - 可以在此基础上进行微调

3. **元素编辑**
   - 点击地质年代块可以单独编辑其属性
   - 可以隐藏不需要的地质年代

4. **导出格式选择**
   - PDF：适合打印和高质量文档
   - SVG：矢量格式，可无限缩放
   - PNG：位图格式，便于分享和查看

5. **方向控制**
   - 使用"向外"刻度方向可以获得最佳视觉效果
   - 时间轴反转可用于特殊场景的时间轴显示

6. **数值显示优化**
   - 勾选"省略小数点后为0的部分"可以让整数显示更简洁
   - 需要精确对比时可以取消勾选保持完整精度

## 注意事项

1. 时间范围输入必须是有效的数字
2. 最小时间必须小于最大时间
3. 刻度间隔不能为0
4. 导出文件时确保有写入权限
5. 大时间范围可能需要调整刻度间隔以获得更好的显示效果

## 故障排除

### 导入错误
如果遇到模块导入错误，请确认已正确安装所有依赖：
```bash
pip install -r requirements.txt --upgrade
```

### 显示问题
如果预览区域显示异常，尝试：
1. 调整标尺长度和厚度
2. 检查时间范围设置是否合理
3. 重启程序

### 导出失败
如果导出功能失败，请检查：
1. 目标路径是否有写入权限
2. 磁盘空间是否充足
3. 文件名是否包含特殊字符

### 编码问题
Windows用户可能会在控制台看到编码警告，这是正常的，不影响程序使用。
