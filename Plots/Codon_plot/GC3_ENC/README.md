# GC3-ENC Plotter

A GUI application for plotting GC3 versus ENC (Effective Number of Codons),
a standard analysis of codon usage bias.

## Contents

| Version | Description |
|---------|-------------|
| [`v1.0.0/`](v1.0.0/) | Initial release |
| [`v2.0.0/`](v2.0.0/) | Intermediate release |
| [`v3.0.0/`](v3.0.0/) | Current release |

Each version contains `gc3_enc_plotter.py` and a `README.md` with the full
usage instructions.

Older test builds are preserved under
[`archive/codon_plot_legacy/GC3_ENC_test/`](../../../archive/codon_plot_legacy/).

## Requirements

- Python 3.6+
- `matplotlib`, `numpy`
- `tkinter` (ships with CPython)

## Usage

```bash
cd v3.0.0
python gc3_enc_plotter.py
```
