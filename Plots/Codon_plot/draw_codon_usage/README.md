## Requirements

- Python 3.7+
- `matplotlib`, `numpy` (see the `dependencies.md` / `依赖项说明.md` in each version)

## Usage

```bash
cd v0.1.1/EN
python draw_codon_usage_en.py -i input.fasta -o output.pdf
```
