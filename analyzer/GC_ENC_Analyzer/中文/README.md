# GC / ENC 密码子使用偏好分析工具

一个带图形界面（GUI）的叶绿体基因组密码子使用偏好分析工具。输入一个文件夹，即可批量计算每个物种每个基因的 GC 含量、ENC 等指标，并自动汇总为三个表格。

## 功能概述

- **输入**：一个文件夹，文件夹内每个 FASTA 文件视为一个**物种**（物种名 = 文件名），文件内每条序列记录视为一个**基因**。
- **基因名自动识别**：自动清除标题行中的坐标、链方向、`join` 等非基因名部分。例如：
  - `>psbD_[33312:34373](+)|NC01.fasta|NC01.fasta` → 基因名 `psbD`
  - `>rps16_join{[5754:5793](-),[4686:4894](-)}|...` → 基因名 `rps16`
- **多线程分析**：分析在后台线程运行，界面实时显示日志与进度条，不会卡顿。

## 计算的指标

| 指标 | 说明 |
|---|---|
| GC1 (%) / GC2 (%) / GC3 (%) | 密码子第 1 / 2 / 3 位的 GC 含量 |
| GC3s (%) | 四倍简并密码子（前两位为 CT、CC、CG、GC、AC、TC、GG、GT）第 3 位的 GC 含量 |
| GC12 (%) | 密码子第 1、2 位的平均 GC 含量 |
| GC总含量 (%) | 全序列 GC 含量 |
| ENC | 有效密码子数（Wright, 1990 标准公式） |
| GC12–GC3 slope | GC12 对 GC3 的最小二乘线性回归斜率 |
| R² | 上述回归的决定系数 |

说明：

- **物种汇总表**中的 slope / R² 为该物种内各基因 GC12 对 GC3 的回归；
- **基因汇总表**中的 slope / R² 为该基因在各物种间 GC12 对 GC3 的回归；
- 参与回归的点数不少于 3 个，否则该两项为空。

## 输出结果

结果保存在所选文件夹下的 `分析结果` 子文件夹中：

| 文件 | 内容 |
|---|---|
| `1_所有物种所有基因_明细.csv` | 每行一个"物种-基因"组合的原始计算值 |
| `2_所有物种平均值.csv` | 每行一个物种，各指标为该物种所有基因的 **平均值 ± 标准差** |
| `3_所有基因平均值.csv` | 每行一个基因，各指标为该基因所有物种的 **平均值 ± 标准差** |

汇总表示例格式：

```
Species    GC1 (%)      GC2 (%)      GC3 (%)      GC3s (%)     GC12 (%)     ENC          GC12–GC3 slope  R²
NC01       46.0 ± 6.6   39.9 ± 6.3   28.9 ± 4.8   27.3 ± 7.7   43.0 ± 5.0   47.5 ± 7.9   0.005           0.000
```

CSV 采用 UTF-8-BOM 编码，可直接双击用 Excel 打开，中文不乱码。
若已安装 `openpyxl`，程序还会额外输出合并的 Excel 文件 `GC_ENC分析汇总.xlsx`（三个工作表）。

## 使用方法

### 环境要求

- Python 3.8 及以上（仅依赖标准库，`tkinter` 随 Python 自带）
- 可选：`openpyxl`（用于输出 xlsx），安装命令：`pip install openpyxl`

### 运行

```bash
python GC_ENC分析工具.py
```

或直接双击运行（前提是 `.py` 已关联到 Python）。

操作步骤：

1. 点击 **浏览…** 选择包含各物种 FASTA 文件的文件夹（如 `2各自共有`）；
2. 点击 **开始分析**，等待日志显示"完成"；
3. 点击 **打开结果文件夹** 查看输出，或手动进入所选文件夹下的 `分析结果` 子文件夹。

> 提示：如需在表格中显示拉丁学名（如 `A. officinalis`），把 FASTA 文件重命名为对应的学名即可，程序以文件名作为物种名。

## 输入数据格式

标准 FASTA 格式即可，示例：

```
>psbD_[33312:34373](+)|NC01.fasta|NC01.fasta
ATGACTATAGCTATTGGTAAATTTGCCAAAGAAGAAAATGATTTATTTGATATTATGGATGAT...
>rps16_join{[5754:5793](-),[4686:4894](-)}|NC01.fasta|NC01.fasta
ATGGTAAAACTTCGTTTGAAACGATGTGGTAGAAAGCAACGAGCGATCTATCGAATCGTTGCA...
```

要求：

- 序列为 CDS（以 ATG 等起始密码子开头，长度为 3 的倍数更佳；程序会自动截掉末尾不完整的密码子）；
- 序列中的非 ACGT 字符会被自动忽略；
- 密码子数少于 3 个的记录会跳过并在日志中给出警告；
- 支持的扩展名：`.fasta`、`.fa`、`.faa`、`.fna`、`.fst`。
