# KaKs 结果分析与筛选工具

> 一个图形化的 KaKs 计算结果筛选与缺失值填充工具。
> 自动识别 KaKs 计算器输出的 `.xlsx` 整理表 或 原始 `.kaks` 文本结果，
> 按基因分组，按缺失比例阈值删除缺失过多的基因，并用本基因其他物种有效值的中位数填充缺失。

## 功能特性

- ✅ **双格式自动识别**：同时支持 `.xlsx`（6 列整理表）和 `.kaks`（KaKs 计算器原始 22 列 tab 分隔结果）
- ✅ **图形化界面**：基于 tkinter 的 GUI，无需命令行
- ✅ **4 个预设阈值**：20% / 30% / 50% / 70% 缺失比例阈值
- ✅ **智能缺失识别**：将 `Ka/Ks = 0` 也视为缺失（KaKs 软件中该值代表 Ka 计算失败的退化值）
- ✅ **中位数填充**：用每个基因其他物种**有效值**（>0）的中位数填充，填充结果不再为 0
- ✅ **自动去重**：处理 `(Species1, Species2, Gene)` 重复行，优先保留 Ka/Ks 有效值
- ✅ **三份输出**：筛选后数据 (xlsx) + 各基因报告 (xlsx) + 简要文本报告 (txt)

## 使用说明

### 1. 选择输入文件

程序支持两种格式自动识别：

| 扩展名 | 格式 | 说明 |
|--------|------|------|
| `.xlsx` / `.xls` | 整理表 | 列：`Species1, Species2, Gene, Ka, Ks, Ka/Ks` |
| `.kaks` / `.tsv` / `.txt` | KaKs 原始输出 | tab 分隔 22 列，首列 `Sequence` 含 `Sp1&Sp2\|gene_mafft` |

点击「**浏览**」选择文件，或点击「**使用示例**」加载自带示例。

### 2. 设置筛选参数

- **缺失比例阈值**：4 个单选按钮
  - `20%` — Ka/Ks 缺失比例 ≥ 20% 的基因被删除
  - `30%` — Ka/Ks 缺失比例 ≥ 30% 的基因被删除
  - `50%` — Ka/Ks 缺失比例 ≥ 50% 的基因被删除
  - `70%` — Ka/Ks 缺失比例 ≥ 70% 的基因被删除
- **中位数填充列**：可勾选 `Ka` / `Ks` / `Ka/Ks`，默认仅勾选 `Ka/Ks`

> **为什么把 Ka/Ks=0 视为缺失？**  
> 在 KaKs 计算器中，当 Ka 计算失败时软件会把 Ka/Ks 输出为 0。这种值没有生物学意义，会显著拉低中位数，因此应视为缺失。中位数仅基于 `Ka/Ks > 0` 的有效值计算。

### 3. 选择输出目录

点击「**浏览**」选择结果保存目录，默认为程序所在目录。

### 4. 点击「**开始分析**」

程序会在后台线程执行分析，进度条实时显示，完成后：
- **运行日志**页：显示处理步骤与结果摘要
- **报告预览**页：表格展示每个基因的统计
- **数据预览**页：原始数据前 500 行

### 5. 查看输出文件

处理完成后日志会输出三个文件的完整路径，可点击「**打开输出目录**」直接查看。

## 核心算法

### 缺失识别

| 列 | 缺失定义 |
|----|----------|
| `Ka/Ks` | NaN **或** = 0（Ka 计算失败的退化值） |
| `Ka` | NaN |
| `Ks` | NaN |

### 缺失率

$$
\text{缺失率} = \frac{\text{Ka/Ks 缺失数}}{\text{总行数}}
$$

### 中位数填充

对保留基因中的每一列，只使用「有效值」计算中位数：

| 列 | 有效值定义 |
|----|------------|
| `Ka/Ks` | `> 0` |
| `Ka` | 非 NaN |
| `Ks` | 非 NaN |

填充时把该列所有缺失值（NaN 或 0）替换为对应的中位数。

### 自动去重

对 `(Species1, Species2, Gene)` 组合去重，优先保留 Ka/Ks 有效值（>0）的行。
原始数据中 `rps7` 等基因因含 `_copy2` 变体而出现 82 行重复，会被自动合并为 41 行。

### 基因名归一化

原始 `.kaks` 中的基因名格式：`ndhB_copy2_mafft`  
归一化后：`ndhB`（同时去掉 `_mafft` 和 `_copy\d+` 后缀）

## 输出文件

每次分析生成 3 个文件：

| 文件 | 内容 |
|------|------|
| `<原名>_filtered_<阈值>pct_<时间>.xlsx` | 筛选+填充后的完整数据 |
| `<原名>_filtered_<阈值>pct_<时间>_report.xlsx` | 每个基因的统计明细 |
| `<原名>_filtered_<阈值>pct_<时间>_summary.txt` | 简要文本报告（含字段说明） |

### 报告字段

| 字段 | 说明 |
|------|------|
| `Gene` | 基因名 |
| `Total` | 该基因在数据中的总行数（物种对数） |
| `MissKa/Ks` | Ka/Ks 列缺失数（NaN 或 =0） |
| `MissKa` | Ka 列缺失数（NaN） |
| `MissKs` | Ks 列缺失数（NaN） |
| `Rate` | Ka/Ks 缺失比例 = MissKa/Ks / Total |
| `+Filled` | 填充后有效数据行数 |
| `MedKa` | Ka 列中位数（基于有效值） |
| `MedKs` | Ks 列中位数（基于有效值） |
| `MedKa/Ks` | Ka/Ks 列中位数（基于有效值） |
| `Status` | 保留 或 删除 |

## 常见问题

### Q1: 为什么 Ka/Ks=0 也要视为缺失？

**答**：KaKs 计算器在 Ka 计算失败时会输出 0 作为占位符，该值没有生物学意义。如果把 0 当作有效值，中位数会被严重拉低（accD 的中位数会从 1.252 降到 0.27），填充后还是 0，达不到填补空缺的目的。

### Q2: 为什么示例数据基因只有 8 个？

**答**：为方便演示和快速运行，示例文件只包含前 8 个基因，但已涵盖各种缺失率（5% ~ 100%）。如需用全部 79 个基因测试，可加载原始文件 `merge.axt.kaks` 或 `0921shaixuan.xlsx`。

### Q3: 阈值该如何选择？

**答**：取决于下游分析对完整性的要求：
- **20%** — 严格，保留的数据完整度高（适合系统发育重建等下游分析）
- **30%** — 中等（KaKs 相关研究的常用阈值）
- **50%** — 宽松，保留更多基因
- **70%** — 最宽松，仅剔除几乎无 Ka/Ks 数据的基因

### Q4: 中位数填充 vs 删除？

**答**：中位数填充会引入统计偏差（低估方差），但能保留更多基因用于下游分析。如果样本量充足，建议直接删除缺失基因而不填充。

### Q5: 程序能处理多大的文件？

答：测试过 7 万行的 `.kaks` 文件，加载约 1 秒，处理约 0.5 秒。如文件更大（百万行以上），可考虑分块处理。
