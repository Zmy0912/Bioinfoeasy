python kaks_analyzer.py

或直接双击 `kaks_analyzer.py`（Windows 关联 .py 到 Python 即可）。

## 3. 详细步骤

### 步骤 1：选择文件

#### 方式 A：使用示例（推荐首次使用）

点击 **「使用示例」**，程序自动填入 `example_kaks.xlsx` 路径并加载。

#### 方式 B：手动选择

点击 **「浏览」**，在文件对话框中选择：
- `.xlsx` 文件 — Excel 整理表（6 列：Sp1, Sp2, Gene, Ka, Ks, Ka/Ks）
- `.kaks` 文件 — KaKs 计算器原始 tab 分隔结果（22 列，首列 Sequence）

#### 步骤完成后

- 程序会自动加载并去重
- 「数据预览」页显示原始数据前 500 行
- 「运行日志」页输出：`加载成功, 共 X 行, Y 个基因, Z 个物种`

### 步骤 2：设置筛选参数

#### 缺失比例阈值（4 选 1）

| 选项 | 保留条件 |
|------|----------|
| 20% | Ka/Ks 缺失率 < 20% |
| 30% | Ka/Ks 缺失率 < 30% |
| **50%**（默认） | Ka/Ks 缺失率 < 50% |
| 70% | Ka/Ks 缺失率 < 70% |

#### 中位数填充列（可多选）

- ☑ **填充 Ka/Ks**（默认）：用本基因其他物种 Ka/Ks 有效值中位数填充
- ☐ 填充 Ka：用本基因其他物种 Ka 中位数填充
- ☐ 填充 Ks：用本基因其他物种 Ks 中位数填充

> **提示**：通常只勾选 Ka/Ks 即可。Ka 和 Ks 列一般没有 0 值问题，填充意义不大。

### 步骤 3：选择输出目录

默认为程序所在目录。如需保存到其他地方，点击 **「浏览」** 选择。

### 步骤 4：开始分析

点击 **「开始分析」**，程序启动后台线程执行：

1. 数据加载与去重
2. 缺失比例统计
3. 按阈值筛选基因
4. 中位数填充
5. 生成 3 份输出文件

进度条实时更新，完成后日志显示结果摘要。

### 步骤 5：查看结果

- **运行日志**：处理步骤与最终结果
- **报告预览**：每个基因的统计表
- **输出目录**：3 份文件（xlsx 数据 + xlsx 报告 + txt 摘要）

## 5. 输入文件要求

### 5.1 Excel 整理表 (`.xlsx`)

列顺序（按列序）：

| 列序 | 列名 | 类型 | 说明 |
|------|------|------|------|
| 1 | Species1 | 文本 | 物种 1（参照物种） |
| 2 | Species2 | 文本 | 物种 2（对比物种） |
| 3 | Gene | 文本 | 基因名 |
| 4 | Ka | 数值 | 同义替换率 |
| 5 | Ks | 数值 | 同义替换率 |
| 6 | Ka/Ks | 数值 | Ka 与 Ks 的比值 |

> 如果首列名为 `Sequence`（含 NaN/None），程序会自动跳过非数据行。

### 5.2 KaKs 原始结果 (`.kaks`)

KaKs_calculator 输出的 tab 分隔 22 列文件。首列 `Sequence` 格式为：

```
Species1<id>&Species2<id>|gene[_copy2][_mafft]
```

例：

```
Asparagus_acutifolius_176986014997886&Asparagus_filicinus_17698599752654|accD_mafft
Asparagus_acutifolius_176986014997886&Asparagus_filicinus_17698599752654|ndhB_copy2_mafft
```

程序会自动解析 `Species1` / `Species2` / `Gene`，并把基因名归一化：

- `ndhB_copy2_mafft` → `ndhB`
- `accD_mafft` → `accD`

## 6. 高级技巧

### 6.1 命令行批量处理

`kaks_analyzer.py` 中的 `KaksProcessor` 类可独立调用：

```python
from kaks_analyzer import KaksProcessor

df = KaksProcessor.load_file("data.xlsx")
result = KaksProcessor.analyze(df, threshold=0.30, fill_columns=["Ka/Ks"])
files = KaksProcessor.export(result, "output/", threshold=0.30,
                              source_file="data.xlsx")
print(result["total_genes"], result["kept_genes"])
```

### 6.2 多次运行

每次「开始分析」会基于已加载的数据重新执行，**不修改源文件**。
如需换数据集，点击 **「浏览」** 重新选择文件。

### 6.3 数据清理建议

如需对所有 4 个阈值都生成报告，重复 4 次「开始分析」即可（结果文件名带时间戳，不会覆盖）。

## 7. 故障排查

| 问题 | 解决方案 |
|------|----------|
| 启动报错 `ModuleNotFoundError: No module named 'pandas'` | 运行 `pip install pandas openpyxl` |
| 启动报错 `tkinter not found` | 重新安装 Python，勾选 tcl/tk 组件 |
| 加载文件报错 `缺少 'Sequence' 列` | 检查 .kaks 文件首行是否为 Sequence\tMethod\t... |
| 报告里所有 MedianKa/Ks 都是 0 | 确认数据中是否有有效 Ka/Ks 值（>0） |
| 程序卡住无响应 | 检查原始文件是否含异常字符（建议先用文本编辑器查看） |

如有问题或建议，请检查源文件后重新运行。
