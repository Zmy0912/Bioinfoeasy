# 更新日志

## v2.0 (2026-09-21)

### 重大改进

#### 1. 智能识别 Ka/Ks=0 为缺失
**问题**：v1.0 中 Ka/Ks 中位数计算包含 0 值，导致填充后 Ka/Ks 仍是 0。

**原因分析**：KaKs 计算器在 Ka 计算失败时输出 0 作为占位符，该值无生物学意义。

**修复**：
- 缺失定义更新：`Ka/Ks` 列的 **NaN 或 =0** 都视为缺失
- 中位数计算：**仅基于 Ka/Ks > 0 的有效值**
- 报告新增 `MissKa` / `MissKs` 列，分别统计 Ka/Ks 列的缺失

**效果**（以 accD 基因为例）：
- 旧版本中位数：≈ 0.27（含 0 值）
- 新版本中位数：**1.252**（仅有效值）
- 填充结果：不再是 0

#### 2. 中位数始终计算（即使未勾选填充）
报告中的 `MedKa` / `MedKs` / `MedKa/Ks` 现在无论是否勾选填充列都会显示，便于用户分析。

#### 3. 基因名归一化增强
- `_mafft` 后缀：去除 ✓
- `_copy\d+` 后缀：去除 ✓（如 `ndhB_copy2_mafft` → `ndhB`）
- 合并 `_copy` 变体（如 `ndhB` 和 `ndhB_copy2` 视为同一基因）

**效果**：原始数据从 86 个"基因"合并为 79 个唯一基因，与整理后的 xlsx 一致。

#### 4. 自带示例文件
- `example_kaks.xlsx`：8 个基因 × 41 个物种的整理表
- `example_kaks.kaks`：相同内容的原始 KaKs 输出
- 程序默认「使用示例」按钮自动加载 `example_kaks.xlsx`

### 其他改进

- 报告字段增加 `MissKa` / `MissKs` / `FilledCount`，信息更完整
- 文本报告末尾增加字段说明

- GUI 默认标题改为 v2.0
