# RSCU Kruskal-Wallis 检验分析软件

## 简介

本软件用于对密码子RSCU（Relative Synonymous Codon Usage，同义密码子使用偏好性）结果进行Kruskal-Wallis非参数检验，分析不同物种间密码子使用偏好的差异。

## 功能特性

- **数据加载**：支持读取xlsx格式的RSCU数据文件
- **物种分组**：支持自动分组和手动定义分组
- **多种分析范围**：可分析全部密码子或按氨基酸筛选
- **Kruskal-Wallis检验**：对每个密码子进行组间差异检验
- **结果解读**：提供详细的统计结果和生物学意义解读
- **可视化**：支持导出箱线图展示差异
- **结果导出**：支持导出完整结果和显著结果（Excel/CSV格式）

## 使用方法

### 1. 运行程序

```bash
python rscu_kruskal_wallis.py
```

### 2. 加载数据

点击"浏览"按钮选择您的RSCU数据文件（xlsx格式），然后点击"加载数据"。

### 3. 设置分组

#### 自动分组
软件会根据物种名前缀自动进行分组。适用于物种名有明确分组特征的数据。

#### 手动分组
对于需要自定义分组的分析（如按地理分布、系统发育关系等），请准备分组文件：

**分组文件格式**（CSV或Excel，两列）：

| Species | Group |
|---------|-------|
| Species_A | Group1 |
| Species_B | Group1 |
| Species_C | Group2 |
| ... | ... |

### 4. 设置分析选项

- **分析范围**：选择全部密码子或按氨基酸筛选
- **显著性水平**：默认为0.05，可根据需要调整

### 5. 执行检验

点击"执行Kruskal-Wallis检验"按钮开始分析。

### 6. 查看结果

结果窗口显示：
- 每个密码子的H统计量和p值
- 显著性标记：`***`（极显著 p<0.001）、`**`（高度显著 p<0.01）、`*`（显著 p<0.05）、`ns`（不显著）
- 各组均值对比和详细解读

### 7. 导出结果

- **导出完整结果**：保存所有密码子的检验结果和分组统计
- **导出显著结果**：仅保存显著差异的密码子结果
- **绘制箱线图**：生成差异显著密码子的箱线图

## 结果解读指南

### Kruskal-Wallis检验原理

Kruskal-Wallis检验是一种非参数检验，用于比较三个或更多独立组之间的差异。它是Mann-Whitney U检验的扩展，不要求数据服从正态分布。

### 结果解读

| 显著性 | p值范围 | 生物学意义 |
|--------|---------|------------|
| 极显著 | p < 0.001 | 不同物种组在该密码子使用上存在非常明显的差异 |
| 高度显著 | 0.001 ≤ p < 0.01 | 物种组间存在明显差异 |
| 显著 | 0.01 ≤ p < 0.05 | 物种组间存在一定差异 |
| 不显著 | p ≥ 0.05 | 物种组间无统计学显著差异 |

### 实际应用场景

1. **物种适应性研究**：比较不同生态适应型物种的密码子使用偏好
2. **系统发育分析**：验证不同进化分支的密码子使用差异
3. **基因表达研究**：分析高表达与低表达基因的密码子偏好差异
4. **比较基因组学**：研究不同物种间的翻译选择压力

## 数据格式要求

输入数据应为包含以下列的Excel文件：

- **第一列**：物种名称（列名建议为"Species"）
- **后续列**：各密码子的RSCU值，列名格式为`密码子(氨基酸)`，如`GCA(Ala)`

示例数据格式：

| Species | GCA(Ala) | GCC(Ala) | GCG(Ala) | GCU(Ala) | ... |
|---------|----------|----------|----------|----------|-----|
| Species_A | 1.19 | 0.62 | 0.40 | 1.79 | ... |
| Species_B | 1.18 | 0.63 | 0.41 | 1.78 | ... |

## 注意事项

1. 每组样本量建议不少于3个，以确保检验结果的可靠性
2. 分组应具有生物学意义，避免随机分组
3. 显著结果需结合生物学背景进行解读
4. 对于大量密码子的分析，Bonferroni校正可作为参考
