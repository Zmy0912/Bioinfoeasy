# CodonW Codon Usage Bias Analyzer

A graphical tool for processing CodonW output results and generating tables suitable for heatmap visualization.

## Features

- 📊 Batch processing of `.blk` files generated by CodonW
- 🔬 Complete statistics for all 61 codons' usage bias
- 🏷️ Automatic labeling of codons with their corresponding amino acids
- 📈 Generates CSV tables ready for heatmap visualization
- 🎨 User-friendly graphical interface
- 🔍 Data quality detection and cleaning recommendations
- ⚡ Support for amino acid-based column sorting

## Installation

Install required dependencies:

```bash
pip install pandas
```

## Usage

### 1. Run the Program

```bash
python codonw_analyzer.py
```

### 2. Interface Operation

- **Input Folder**: Select the folder containing CodonW result files (`.blk` files)
- **Output Folder**: Choose the location to save results (defaults to the input folder)
- **Metric**: Select RSCU (Relative Synonymous Codon Usage) or Count (Codon Count)
- **Sort by Amino Acid**: Check this option to group codon columns by amino acid
- Click "Start Analysis" button to execute the analysis

## Output Files

### Heatmap Tables

- **Unsorted**: `codonw_heatmap_rscu.csv` or `codonw_heatmap_count.csv`
- **Sorted**: `codonw_heatmap_sorted_rscu.csv` or `codonw_heatmap_sorted_count.csv`

### Data Quality Report

- `codonw_data_quality_report.txt`: Contains data quality analysis and cleaning recommendations

## Heatmap Table Format

| Column | Description |
|--------|-------------|
| Species | Species name |
| UUU(Phe) | Codon(Amino acid) |
| UUC(Phe) | Codon(Amino acid) |
| ... | Other codons |
| Data | RSCU value or codon count |

## Amino Acid Sorting

When "Sort by amino acid" is checked, codon columns are arranged in the following standard biochemical order:

```
Ala → Arg → Asn → Asp → Cys → Gln → Glu → Gly → His → Ile →
Leu → Lys → Met → Phe → Pro → Ser → Thr → Trp → Tyr → Val
```

Multiple codons within the same amino acid are sorted alphabetically.

**Advantages**:
- Facilitates observation of different codon preferences for the same amino acid in heatmaps
- Amino acid grouping makes results more intuitive
- Easier to identify codon usage patterns

## Data Quality Report Contents

1. **Missing Codon Detection**: Identifies missing codons for each species
2. **Zero-Count Codons**: Lists codons with count of 0 (may affect statistical analysis)
3. **RSCU Outliers**: Identifies codons with RSCU values > 2.0 (potential outliers)
4. **Cleaning Recommendations**: Provides suggestions for data processing and cleaning

## Heatmap Visualization Example

Using Python to create a heatmap:

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Read data
df = pd.read_csv('codonw_heatmap_sorted_rscu.csv')

# Set species names as index
df.set_index('Species', inplace=True)

# Create heatmap
plt.figure(figsize=(16, 10))
sns.heatmap(df, cmap='viridis', center=1.0,
            cbar_kws={'label': 'RSCU Value'})
plt.title('Codon Usage Bias Heatmap')
plt.xlabel('Codon(Amino acid)')
plt.ylabel('Species')
plt.tight_layout()
plt.savefig('codonw_heatmap.png', dpi=300)
plt.show()
```

## Notes

1. Ensure the input folder contains only `.blk` format CodonW result files
2. Data with missing codons may need manual completion or exclusion
3. Zero-count codons may cause bias in heatmap analysis; decide whether to keep them based on your analysis needs
4. RSCU outliers should be checked in the original data or analysis workflow
