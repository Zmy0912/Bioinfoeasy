# Codon Usage Bias Analysis

Tools for analysing codon usage bias in (chloroplast) genomes.

## Contents

| Module | Description |
|--------|-------------|
| [`codonw_analyzer/`](codonw_analyzer/) | CodonW (blk) codon usage bias statistics; see [`blk_analyzer/`](codonw_analyzer/blk_analyzer/) for the CN/EN tools |
| [`gc_analyzer/`](gc_analyzer/) | GC content analysis |
| [`gc12_gc3_regression_analyzer/`](gc12_gc3_regression_analyzer/) | GC12-GC3 regression (neutrality/selection) analysis |
| [`gc3enc_analyzer/`](gc3enc_analyzer/) | Multi-species ENC-GC3 analysis |
| [`rscu_kruskal_wallis/`](rscu_kruskal_wallis/) | RSCU Kruskal-Wallis statistical test (CN/EN) |
