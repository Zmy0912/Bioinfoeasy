# 叶绿体基因组组装结果比对工具

## 简介

本工具用于比较两个组装的叶绿体基因组序列与参考序列，自动判断**哪个组装结果更正确**。程序通过多维度综合评分，输出直观的比对结果和可视化图表。

**特色功能**：独创的片段位置映射法，可检测传统全局比对和 k-mer 分析难以发现的**四区结构错误**——包括 IR 互换、局部倒位和接头顺序错误。

## 系统要求

- **Python** 3.7 及以上
- **Biopython** 1.76 及以上

## 安装

```bash
pip install biopython
```

## 快速开始

1. 双击 `cp_genome_comparison.py` 启动程序
2. 选择三个 FASTA 格式文件：
   - **参考序列**：已知的叶绿体基因组参考序列
   - **组装序列1**：第一次组装得到的结果
   - **组装序列2**：第二次组装得到的结果
3. 点击 **「开始分析」**
4. 查看结果：程序自动判断哪个组装更正确

## 界面说明

程序包含三个标签页：

| 标签页 | 功能 |
|--------|------|
| 📊 综合结果 | 得分对比、基本统计、K-mer 分析、**四区结构分析摘要**和最终结论 |
| 📋 详细比对 | 各项指标的详细数据（长度、GC、比对、覆盖度）及**结构分析详情** |
| 📈 一致性分布 | 滑动窗口一致性曲线图，直观展示不同区域的相似度 |

## 评分体系

综合评分 = 基础分（满分100） + 结构完整性加分（最高+5分）：

| 维度 | 权重 | 说明 |
|------|:----:|------|
| 一致性得分 | 40% | 基于 Biopython 分块全局比对的一致性 |
| 覆盖度得分 | 30% | 组装序列对参考序列的 k-mer 覆盖程度 |
| 长度相似度 | 15% | 组装序列与参考序列长度的接近程度 |
| GC 相似度 | 15% | GC 含量差异 |
| **结构完整性** | **+5分** | **四区结构正确性（IR互换、倒位、接头错误检测）** |

> 结构完整性评分规则：无错误 +5.0；全局翻转（非错误）+4.5；重排/倒位按程度扣分；IR互换 -2.0

## 分析原理

### 核心算法

1. **K-mer 相似度分析**（k=31）  
   将序列分解为长度为 31 的短串，比较 k-mer 集合的 Jaccard 相似系数和共享比例。此方法对序列重排不敏感。

2. **分块全局比对**  
   对大型基因组（>50kb），程序采用分块策略：将参考序列切为 5000bp 的块，每块通过 k-mer 定位到组装序列中的最佳匹配区域，再做小范围全局比对，最后汇总结果。

3. **滑动窗口分析**  
   以 5000bp 窗口、2000bp 步长扫描参考序列，通过 k-mer 匹配计算每个窗口的一致性，生成沿基因组分布的一致性曲线。

4. **覆盖度计算**  
   检查参考序列的 k-mer 在组装序列中的出现比例，评估组装的完整性。

5. **四区结构分析**（v2.0 新增）  
   将参考序列等分为20个片段，通过正向/反向互补 k-mer 双重匹配定位每段在组装中的位置和方向。分析片段排列模式：
   - **全局翻转**（≥85%片段反向）：组装整体为参考反向互补，非结构性错误
   - **位置跳变**：片段在组装中不按参考顺序排列，提示重排或IR互换
   - **局部倒位**：部分连续片段以反向互补方式匹配
   - **折返模式**：IR互换的典型特征——片段在组装中先递增后折返

   同时使用8个等距检查点的k-mer指纹验证序列顺序，确认错误类型。

### 结构性错误类型

| 错误类型 | 描述 | 检测方法 |
|----------|------|----------|
| IR互换 | IRa/IRb 区域在组装中被互换 | 位置折返 + 多处跳变 + 局部倒位 |
| 局部倒位 | 部分区域以反向互补方向组装 | 连续片段方向反转 |
| 接头错误 | LSC/SSC/IR 边界连接顺序错误 | 检查点k-mer顺序验证 |
| 全局翻转 | 整个组装序列为参考反向互补 | ≥85%片段反向（非错误） |

### 输出结果

- 组装序列的总分和排名（含结构得分）
- 详细的比对统计数据
- 滑动窗口一致性分布图
- 四区结构分析详情
- 可导出为文本报告

## 文件格式

支持以下 FASTA 扩展名：`.fasta` `.fa` `.fna` `.fas` `.txt`

程序自动处理编码问题（UTF-8 / GBK），支持包含中文描述行的 FASTA 文件。

## 注意事项

- 叶绿体基因组通常为 120–180 kb，程序对大基因组自动使用内存优化的分块比对
- 比对过程可能需要数分钟，请耐心等待
- 若两个组装得分接近，建议检查滑动窗口一致性分布图和结构分析结果，关注是否存在大片段重排、倒位或IR互换
- 四区结构分析仅对长度大于30 kb的序列启用
