# Chloroplast Genome Analysis

A collection of tools for chloroplast genome sequence analysis.

## Contents

| Module | Description |
|--------|-------------|
| [`Codon/`](Codon/) | Codon usage bias analysis (CodonW, GC content, GC12-GC3 regression, GC3-ENC, RSCU Kruskal-Wallis) |
| [`cp_genome_comparison/`](cp_genome_comparison/) | Compare two chloroplast genome assemblies against a reference to determine which is more accurate (CN/EN) |
| [`quadrants_analyzer/`](quadrants_analyzer/) | Four-region (quadrant) analysis of chloroplast genomes |

## Requirements

- Python 3.7+
- See each sub-module's `requirements.txt` for specific dependencies.
