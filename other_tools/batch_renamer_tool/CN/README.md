# 批量重命名工具

这是一个用于批量替换文件中名称的图形化界面工具。

## 功能特点

- 支持加载TXT格式的名称映射文件(第一列为原名,第二列为新名称,用制表符分隔)
- 支持选择任意类型的目标文件进行名称替换
- 提供左右分屏预览,可同时查看原始内容和替换后的内容
- 显示替换统计信息
- 操作简单直观的图形化界面

## 使用方法

### 1. 运行程序

```bash
python batch_renamer.py
```

### 2. 操作步骤

1. **选择名称映射文件**: 点击"浏览..."按钮选择包含原名和新名称对应关系的TXT文件
   - 文件格式要求:每行两列数据,用制表符(TAB)分隔
   - 第一列:原名
   - 第二列:新名称

2. **选择目标文件**: 点击"浏览..."按钮选择需要进行名称替换的文件

3. **选择输出文件**: 点击"浏览..."按钮选择或输入输出文件路径

4. **加载名称映射**: 点击"加载名称映射"按钮,程序会自动解析映射文件

5. **预览替换**: 点击"预览替换"按钮,左侧显示原始内容,右侧显示替换后的内容

6. **执行替换**: 确认预览无误后,点击"执行替换"按钮,程序会将结果保存到输出文件

## 示例

### 名称映射文件示例(新建 文本文档.txt)

```
登录号	学名
OQ851342.1	Asparagus officinalis
NC_086747.1	Asparagus subscandens
...
```

### 注意事项

- 名称映射文件必须使用制表符(TAB)分隔两列数据
- 程序会按照旧名称长度从长到短进行替换,避免部分匹配问题
- 替换操作是不可逆的,建议先预览确认无误后再执行
- 支持所有文本格式的文件

## 系统要求

- Python 3.6+
- tkinter(通常随Python一起安装)

本程序只使用Python标准库,无需安装额外依赖。
