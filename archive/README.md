# Archive

This directory keeps **superseded tool versions** for reference only.
Nothing here is part of the supported tool set, and the content is excluded
from the project structure documented in the root `README.md`.

## Contents

| Path | Description |
|------|-------------|
| `codon_plot_legacy/GC12_GC3/` | Early GC12-GC3 plotter, superseded by `Plots/Codon_plot/GC12_GC3/`. |
| `codon_plot_legacy/GC3_ENC/` | Early GC3-ENC plotter (v1.x) plus the old `测试版本` test build. |
| `codon_plot_legacy/GC3_ENC_test/` | Legacy GC3-ENC test build that used to sit under `GC3_ENC/`. |

## Current tools

For the maintained versions, use:

- `Plots/Codon_plot/GC12_GC3/` — GC12-GC3 neutrality plots
- `Plots/Codon_plot/GC3_ENC/` — GC3-ENC plots
- `Plots/Codon_plot/PR2_plot/` — PR2-Plot (parity rule 2) plots
- `Plots/Codon_plot/draw_codon_usage/` — codon usage bias plots

> Files in `archive/` may rely on outdated APIs and are not guaranteed to run.
> They are retained purely for historical traceability.
